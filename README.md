# Pulse — Coordination Intelligence

> An AI-powered conversation analysis tool that turns team discussions into clear, actionable insights.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Open%20App-black?style=for-the-badge)](https://coordination-pulse.lovable.app/)

## Overview

Pulse is an AI-powered coordination intelligence application designed to help teams understand what is happening across their conversations.

It analyzes meeting notes, chat threads, and team discussions to identify three key areas:

- **Gone Dark** — unresolved, unanswered, blocked, or abandoned items
- **In Motion** — active tasks with clear ownership and progress
- **Confirmed** — agreed decisions, facts, and commitments

Instead of manually reviewing long conversations, Pulse turns unstructured communication into structured, actionable information.

## ✨ Key Features

- 🤖 AI-powered conversation analysis
- 📋 Extracts actionable tasks and follow-ups
- 👤 Identifies task ownership when possible
- ⚠️ Detects unresolved and unanswered issues
- ✅ Identifies confirmed decisions and commitments
- 📊 Organizes insights into a clear three-category dashboard
- 🔄 Start a new conversation and reset the current analysis
- 📱 Responsive interface for different screen sizes
- 🛡️ Safe API and error handling
